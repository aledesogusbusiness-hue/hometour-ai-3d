# HomeTour.ai — Interactive 3D Experience

Premium single-page prototype for HomeTour.ai using the supplied logo and Gaussian Splat `.spz` scene.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Deploy to GitHub / Vercel

Upload the entire project to a repository. Vercel can detect the Vite project automatically.

The 3D asset is:

`public/assets/bedroom.spz`

Replace that file with another compatible `.spz` capture if you want to create another tour.

## Included

- HomeTour.ai branding based on the supplied logo
- Responsive premium landing page
- Interactive Gaussian Splat 3D viewer
- Orbit / zoom controls
- Fullscreen mode
- Mobile layout
- Modal explaining the product
- Vite production build
